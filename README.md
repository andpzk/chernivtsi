# Тредсові Чернівці

Статичний огляд збережених обговорень у Threads.

Інтерфейс — мінімалістичний довідник із рейтингом згадок, клікабельним
топ-10, розподілом назв за категоріями та діаграмами тем переїзду.
Є пошук, сортування за згадками/авторами/абеткою та джерела в розкривних
рядках. Реєстрації й обраного немає. Вибраний користувачем дизайн: варіант 3.

Сайт: https://andpzk.github.io/chernivtsi/

## Оновлення 2026-09-18

- 1448 відповідей у 32 гілках після об'єднання збережених зборів.
- 133 картки з попереднього каталогу мають знайдені згадки в оновленому корпусі.
- Теми переїзду перераховані за 448 відповідями у 8 гілках.
- Картки містять посилання на відповіді-джерела.

Новий збір із Threads не проводився. Згадки рахуються за явними збігами назв
і варіантами написання, переліченими в `site-report.json`; це не рекомендації
та не оцінка якості. Нові назви поза попереднім каталогом ще не розмічені.
Частоти тем отримані за ключовими словами, без класифікації тональності.
Покриття гілок неповне, а кількість збережених відповідей не дорівнює
лічильнику Threads. Старі непідтверджені ціни, адреси, графіки та вердикти
не подаються як актуальні дані.

## Файли та розгортання

- `index.html` — самодостатня сторінка з пошуком, фільтрами й діаграмами.
- `template.html` — шаблон із маркером `__SITE_DATA__` для даних збірки.
- `site-report.json` — агреговані підрахунки, варіанти назв і посилання на джерела.

GitHub Pages публікує корінь гілки `main`. Build-залежностей немає.
Для локального перегляду: `python -m http.server 8080`.
Вихідний приватний архів аналізатора не входить до репозиторію.

## Рейтинг та антирейтинг

Три режими: усі згадки, явні позитивні відгуки та явні негативні відгуки. Контекстна розмітка ШІ охоплює 300 відповідей із збігами назв; 155 оцінок прив’язано до конкретних назв. Неоднозначні репліки та самореклама виключені з рейтингу тональності. Це не незалежна перевірка тверджень авторів.

Кожна оцінка містить першоджерело та короткий переказ. Повтор однакового тексту одного автора враховується один раз на назву й тональність; доступне сортування за різними авторами. Нуль оцінок не означає відсутність скарг чи рекомендацій. Нового збору даних не було.
